📚 5G Service-Based Architecture Guide

🐳 Method 1: Terminal Deployment

  1. Open the SBA Dashboard and click the Terminal button.
  2. Run docker compose -f docker-compose.yml up -d to deploy all NFs.
  3. Verify network creation using docker network ls.
  4. Check NF IP allocation using docker network inspect oaiworkshop.
  5. Stop all NFs using docker compose -f docker-compose.yml down.

🖱️ Method 2: Manual NF Configuration

  1. Select an NF from the dashboard to configure manually.
  2. Enter IP, port, and protocol, then click Start NF.
  3. Wait a few seconds for the NF to stabilize and connect.
  4. Repeat the process to start all required NFs.

🚀 Method 3: One-Click Core Deploy

  1. Use Core Deploy button for one-click deployment of all NFs.
  2. Check logs to confirm all NFs are started and connected.

📡 Connectivity Test

  1. Open an NF terminal and run ping <Target_NF_IP> to test connectivity.
  2. Ensure replies with 0% packet loss to confirm stable communication.
